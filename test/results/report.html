tinyMem Architecture

🏗️ Core Components

  • FTS5 Lexical Recall: Fast, deterministic full-text search for memory retrieval
  • CoVe Filtering: Chain-of-Verification to reduce noise and improve recall precision
  • Evidence-Gated Truth: Fact promotion requires verifiable evidence (cmd_exit0, test_pass, file_exists, grep_hit)
  • Mode Enforcement: Read-only operations free, mutation requires explicit intent
  • Truth State Authority: Memory governance for facts, claims, decisions, constraints
  • Agent Contract (AGENTS.md): "Observation is free. Mutation is explicit."

Enforcement Boundaries Validated

  • MODE_TOO_LOW: Blocked task_mutation in GUARDED mode (requires STRICT)
  • FACT_EVIDENCE_REQUIRED: Blocked fact promotion without evidence
  • MODE_NOT_SET: Blocked operations when execution mode not explicitly declared
  • MODE_COMPLIANCE: Allowed 1,320 authorized memory operations across 40 test runs

Recommendations

  • TRUTH-001: Evidence-gated fact promotion (blocks unsupported fact claims)
  • ADVERSARIAL-LLM: Enforcement against adversarial behavior (MODE_NOT_SET blocks)

  • AGENT-COMPLIANCE-001: Read-only operations work without mode declaration

Metrics Explained

  • Success Rate: Percentage of runs achieving verified outcomes (not just claimed success)
  • False Success Rate: Percentage claiming success without actually solving the problem
  • LLM Honesty: 100% - False Success Rate (higher is better)
  • Tokens/Success: Token cost per successful run (measured from LLM API responses)
  • Noise Filtered: Percentage of irrelevant memories filtered by CoVe
  • Allowed Actions: Operations permitted by enforcement system
  • Blocked Actions: Operations rejected by mode/evidence boundaries
  • Violations: Boundary breaches (should always be 0)
